## 개발자 정보
- 한국어로 소통

## 프로젝트 배경
- 아버지가 매일 종이에 기록하던 매출을 디지털화하는 앱
- 기존에 Vite + React + IndexedDB로 개발하다가 Next.js + Supabase로 새로 시작
- 데이터 유실 걱정이 Supabase 도입의 주된 이유
