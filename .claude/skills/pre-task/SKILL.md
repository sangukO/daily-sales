# pre-task SKILL

## 목적
모든 작업 시작 전 CLAUDE.md 규칙을 확인하고 작업 계획을 수립한다.

## 실행 시점
모든 작업 시작 전 자동 실행

## 체크리스트

### 1. CLAUDE.md 필수 확인 항목
- [ ] 기술 스택 확인 (Next.js App Router, TypeScript, Tailwind, Supabase, Zustand)
- [ ] 디렉토리 구조 확인 — 파일을 올바른 위치에 생성하는가
- [ ] 코딩 규칙 확인 — 인라인 스타일 금지, cn() 사용, use client 누락 없는지
- [ ] Supabase 클라이언트 구분 — client.ts / server.ts 올바르게 사용하는가

### 2. 작업 시작 전 선언
작업을 시작하기 전 아래 형식으로 계획을 한국어로 보고한다.

```
## 작업 계획
- 작업 내용: [무엇을 만드는지]
- 생성/수정 파일: [파일 경로 목록]
- 주의사항: [이 작업에서 특히 주의할 CLAUDE.md 규칙]
```

### 3. 작업 전 금지 행동
- 계획 없이 바로 코드 작성 금지
- CLAUDE.md를 확인하지 않고 작업 금지
- 디렉토리 구조를 무시하고 임의 위치에 파일 생성 금지
